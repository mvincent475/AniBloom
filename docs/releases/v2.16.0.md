# Upstream v2.16.0 — Nine-catalog discovery and compatibility

> These are upstream AniBloomHQ release notes. AniBloom Personal maintains independent version and deployment history.

This document describes the v2.16.0 source changes. Production availability is determined by the actual Vercel deployment and [release tracker #548](https://github.com/AniBloomHQ/AniBloom/issues/548), not by this document or an unreleased Git commit.

## What changed

- **One nine-catalog manifest:** Current, previous, and upcoming seasonal series and movies; Upcoming and Previous 3 Days; Top Anime of the Season. Nuvio controls which Home rows appear. The retired Airing Today and Upcoming 7 Days catalog routes now return 404.
- **Anime titles and discovery:** English, Romaji, and Native/Japanese catalog name options; optional genre filtering; improved title/synonym matching; Japan Standard Time season calculations; bounded upstream ranking.
- **Identity and posters:** Expanded provider identity regression coverage; BetterPosters default URLs only for compatible IMDb identities, with Japanese poster text for the Native variant and original AniList cover fallback for unmatched identities. Actual BetterPosters availability and Nuvio client image fallback depend on external services and client behavior.
- **Cost/reliability:** Reactive stale cache, distributed request limiting and coalescing remain; mock-only offline cold/warm/stale/Redis-outage profiling, bounded manual snapshot capture, consistent nine-catalog release checks and safe self-hosted public-origin configuration.
- **Phase A compatibility:** Offline contract tests cover all 56 Vercel rewrite rules. The two rolling three-day catalogs still cap AniList schedule collection at eight pages; development diagnostics now flag *possible* truncation when the cap is reached without enough unique results. No extra AniList page is requested, no public catalog schema or upstream budget change.
- **Home setup:** Top Anime is ninth in the manifest and can be hidden initially in some Nuvio builds. Enable/reorder it from Settings → Home or Catalog Customization; do not install both canonical and compatibility-alias manifests.

## Release validation checklist

The controlled release must pass required CI, full Git-history secret scanning, and CodeQL before deployment. Validate production version and all nine manifest IDs in English/Romaji/Native, core catalog series/movie routes, optional genre and search, rolling windows, ranked catalog, legacy manifest aliases, retired 404s, metadata 404 boundary, homepage trophy, and poster language. Confirm no unexpected CPU/rate-budget impact. Record the actual deployment ID/SHA and release tag **only after** success.

The internal deployment checkpoint was reset from 3 to 0 before this release, preserving historical `totalDeployments=167`. A successful deployment increments the checkpoint; the reset does not alter Vercel Hobby limits or usage. Do not reinstate scheduled production availability polling or add paid observability without a separate decision.

## Known limitations

- A full final upstream schedule page at the fixed page budget can make rolling results incomplete; the opt-in diagnostic warns of possible truncation but cannot prove AniList has more pages.
- External poster URLs can fail for individual titles; a returned URL is not evidence the image was retrieved successfully by Nuvio.
- Nuvio can cache old addon manifests, and existing installations may need a refresh or reinstall after the change.
- Provider-based title identity matching and results depend on upstream availability, mapped identifiers and installed metadata providers.
